# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep the discussion about the work.
Harassment, personal attacks and discrimination of any kind have no place
here, in issues, pull requests or anywhere else the project is discussed.

If someone's behaviour is a problem, report it privately to the maintainer
through the contact details on
[their GitHub profile](https://github.com/burakgon). Reports are kept
confidential.
